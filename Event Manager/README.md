# DSI Student Portal Website

A web-based version of the DSI (Dayananda Sagar Institute) student portal, featuring a modern interface with an Events section and AI chatbot assistant.

## Features

### 🎯 Main Features
- **Student Dashboard**: Complete student information display with academic details
- **Feature Cards**: Access to all portal functions including:
  - Academic Calendar
  - Time Table
  - Attendance
  - LMS (Learning Management System)
  - Announcements
  - Transport
  - Internal Assessment
  - Exam Schedule
  - Results
  - Fees
  - Feedback
  - Notifications
  - Circular
  - LMS Test Results

### 🆕 New Features Added
- **Events Section**: Displays upcoming college events with detailed information
- **AI Chatbot**: Intelligent assistant that can answer questions about all portal features

## How to Use

### Running the Website
1. Open a terminal/command prompt
2. Navigate to the project directory
3. Run: `python -m http.server 8000` (or any available port)
4. Open your browser and go to `http://localhost:8000`

### Using the Events Feature
1. Click on the "Events" card on the main dashboard
2. View upcoming events with dates, times, and venues
3. Events include technical symposiums, cultural fests, holidays, and more

### Using the AI Chatbot
1. Click on the "AI Assistant" card on the main dashboard
2. Type your questions about any portal feature
3. The chatbot will provide detailed information and help

## AI Chatbot Capabilities

The AI assistant can help you with information about:
- Academic Calendar and important dates
- Time Table and class schedules
- Attendance tracking and requirements
- LMS access and course materials
- Exam schedules and results
- Fees and payment information
- Events and announcements
